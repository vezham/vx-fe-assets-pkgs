# Vezham Icons

Vezham Icons is an SVG icon library for web, mobile, and design tools. Choose from outline, filled, duotone outline, and duotone filled weights.

[Browse the icon gallery](https://oss.vezham.com/docs/assets/icons) · [Read the developer guides](https://oss.vezham.com/docs/assets/guides)

## 🗂️ Packages List

| Package                                                       | Use it for                                            |
| ------------------------------------------------------------- | ----------------------------------------------------- |
| [`@vezham/icons`](./packages/icons)                           | JavaScript, HTML, and standalone SVG files            |
| [`@vezham/icons-react`](./packages/icons-react)               | React applications                                    |
| [`@vezham/icons-react-native`](./packages/icons-react-native) | React Native and Expo applications                    |
| [`@vezham/icons-vue`](./packages/icons-vue)                   | Vue applications                                      |
| [`@vezham/icons-svelte`](./packages/icons-svelte)             | Svelte applications                                   |
| [`vezham_icons`](./packages/icons-flutter)                    | Flutter and Dart applications                         |
| [`@vezham/icons-mcp`](./packages/icons-mcp)                   | Icon search and code snippets through MCP and the CLI |
| [`@vezham/icons-figma`](./packages/icons-figma)               | Inserting vector icons in Figma                       |
| [`@vezham/icons-vscode`](./packages/icons-vscode)             | Browsing and inserting snippets in VS Code            |
