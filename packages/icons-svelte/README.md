# @vezham/icons-svelte

Use Vezham Icons as Svelte components. Import each icon by its PascalCase name.

## Install

```sh
npm install @vezham/icons-svelte
```

## Use

```svelte
<script>
  import Home from '@vezham/icons-svelte/Home'
</script>

<Home size={24} weight="filled" aria-hidden="true" />
```
