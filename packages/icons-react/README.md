# @vezham/icons-react

Use Vezham Icons as React components. Import each icon by its PascalCase name.

## Install

```sh
npm install @vezham/icons-react
```

## Use

```tsx
import Add from '@vezham/icons-react/Add'

export function AddIcon() {
  return <Add size={24} aria-hidden="true" />
}
```
