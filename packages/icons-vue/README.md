# @vezham/icons-vue

Use Vezham Icons as Vue 3 components. Import each icon by its PascalCase name.

## Install

```sh
npm install @vezham/icons-vue
```

## Use

```vue
<script setup>
import Home from '@vezham/icons-vue/Home'
</script>

<template>
  <Home :size="24" weight="filled" aria-hidden="true" />
</template>
```
