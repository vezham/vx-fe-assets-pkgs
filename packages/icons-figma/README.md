# @vezham/icons-figma

Browse Vezham Icons and insert editable vectors into a Figma design file.

## Install

Download the plugin archive from npm.

```sh
npm pack @vezham/icons-figma
```

Extract the `.tgz` archive. In the Figma desktop app, select **Plugins → Development → Import plugin from manifest** and open `package/dist/manifest.json` from the extracted archive.

## Use

Run **Vezham** from the Plugins menu. Search for an icon, select a weight, and click the icon to insert it into the current design.

[Figma guide](https://oss.vezham.com/docs/assets/guides/figma)
