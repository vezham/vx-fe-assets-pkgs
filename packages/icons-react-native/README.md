# @vezham/icons-react-native

Use Vezham Icons in React Native and Expo with `react-native-svg`.

## Install

```sh
npm install @vezham/icons-react-native react-native-svg
```

In Expo projects, use `npx expo install react-native-svg` to select the version compatible with your Expo SDK.

## Use

```tsx
import Home from '@vezham/icons-react-native/Home'

export function HomeIcon() {
  return <Home size={24} color="#2563eb" />
}
```
